# 85 — חלון הייבוא ממיין את מערך הקטגוריות של האירוע במקום

## מה זה

חלון הייבוא בונה את רשימת הקטגוריות שלו ממערך הקטגוריות של האירוע, **וממיין
אותו במקום ולא עותק שלו.**

המערך הזה אינו שלו. הוא או המערך שיושב בזיכרון האפליקציה בתוך האירוע, או המערך
של טופס האירוע שפתח את החלון בהגירה חכמה. **בשני המקרים מישהו אחר מחזיק בו.**

**וזה קורה בתוך חישוב ממוזכר**, כלומר בתוך קוד שאמור רק לחשב ולא לשנות דבר.

## למה זה לא התפוצץ עד היום

**כי המיון הוא לפי אותו שדה שהרשימה ממילא מסודרת לפיו ברוב המקרים.** כשהסדר
כבר נכון, מיון במקום אינו משנה דבר.

**ומה שכן יכול לקרות:** אירוע שקטגוריותיו נשמרו בסדר אחר, או קטגוריה שנוספה
ידנית עם מספר סדר גבוה, יראה סדר קטגוריות שונה במסכים אחרים אחרי שהמארגן פתח
את חלון הייבוא. **בלי שהוא שמר כלום.**
