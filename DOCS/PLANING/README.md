## ארכיטקטורה — מה שחשוב לדעת

לפני שנוגעים במשהו, שלוש עובדות שמבלבלות בפרויקט הזה:

**1. שני מסלולי פריסה נפרדים.**

| מה | איך נפרס | מופעל על ידי |
|---|---|---|
| פרונטאנד (`src/`) | Netlify | אוטומטי בכל push ל-`main` |
| Cloud Functions (`functions/`) | `firebase deploy --only functions` | **ידני בלבד** |

דחיפה ל-GitHub **לא** מעדכנת את הפונקציות. זו הייתה הסיבה לתקלה ב-23/08 — הפרונטאנד החדש דיבר עם פונקציה ישנה.

**2. המסד הוא Realtime Database, לא Firestore.**

אפס קבצים משתמשים ב-`firebase/firestore`. שבעה משתמשים ב-`firebase/database`. אם מישהו מריץ `firebase init` — **לא לבחור Firestore**. זה כבר קרה פעם והשאיר קבצי scaffolding שכמעט תקעו deploy.

**3. פריסת פונקציות דורשת timeout מוגדל.**

```powershell
$env:FUNCTIONS_DISCOVERY_TIMEOUT=60; firebase deploy --only functions
```

בלי זה הפריסה נכשלת עם `Timeout after 10000`. הסיבה: טעינת `firebase-admin` איטית מכדי להספיק בחלון ברירת המחדל של 10 שניות.
