והנקודה המשלימה: לחמישה מהענפים היה `ahead: 0` — אפס קומיטים ייחודיים. כל שורת קוד שבהם כבר הייתה ב-`main`. מחיקתם הסירה רק תווית, לא היסטוריה.

## נוהל להמשך

כדי לא לחזור לאותו מצב:

1. **ענף לכל משימה, ומיזוג מיד בסיום.** ענף שחי יותר משבועיים הופך לחוב.
2. **למחוק ענף מיד אחרי מיזוג.** אם `ahead: 0` — אין מה לשמור.
3. **`git fetch` לפני כל תחילת עבודה.** זו הבדיקה שהייתה מונעת את התקלה של 23/08.

בדיקה מהירה של מצב כל הענפים מול main:

```bash
git fetch --prune && git branch -r --merged origin/main
```

כל מה שמופיע ברשימה הזו (חוץ מ-`main` עצמו) בטוח למחיקה.
