## ⚠️ עובדות הפרויקט שאסור לגלות מחדש בכל סבב

**כולן נמדדו. הן קיצור דרך, לא תחליף לאימות מצב.**

**מיזוג ל-`main` הוא פריסה לפרודקשן.** Netlify בונה ומעלה אוטומטית על דחיפה.
**כלומר מיזוג הוא שחרור, ואין שלב ביניים.**

**⚠️ ושני דברים אינם עולים עם המיזוג ונפרסים ידנית:**

```powershell
firebase deploy --only database --project shishi-shitufimt
$env:FUNCTIONS_DISCOVERY_TIMEOUT=60; firebase deploy --only functions --project shishi-shitufimt
```

**בלי דגל ההשהיה, פריסת הפונקציות נכשלת עם `Timeout after 10000`.**

**`npm run lint` שבור.** רשומה 16. **אל תריץ ואל תתקן אגב.**

**בדיקת הטיפוסים היא `tsc --noEmit -p tsconfig.app.json`.** ⚠️ **בלי הדגל היא
אינה בודקת דבר**, כי קובץ ההגדרות הראשי ריק ומפנה הלאה. **קו הבסיס: מאה
וארבעים שגיאות קיימות.**

**בדיקות: `node --test test/import/*.test.mjs`.** ⚠️ **נתיב תיקייה נכשל**,
צריך את התבנית. **ויש סוויטת חוקי מסד ב-`test/rules/`** שדורשת JDK 21, ופקודת
ההרצה המדויקת ב-`test/rules/README.md` **כולל דגל ריצה טורית שאין להשמיט.**

**האתר החי: `shishi-shitufi.netlify.app`.** שאר הקישורים ב-`README.md` שבשורש
רקובים, רשומה 22.

**⚠️ ואימות פריסה נעשה מול האתר החי ולא לפי דיווח:** למשוך את החבילה
שמוגשת ולחפש בה מחרוזת שהסבב הוסיף. **זה תפס סבבים שדיווחו "נפרס" ולא נפרסו.**
