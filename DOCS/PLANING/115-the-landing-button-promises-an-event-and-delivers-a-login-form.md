## מה שהמארגן החדש עובר

**הוא לוחץ על הכפתור הראשי בעמוד הנחיתה**, שכתוב עליו "נרשמים ופותחים אירוע,
בחינם".

**ונוחת על מסך שכותרתו "התחבר לחשבונך כדי לנהל אירועים"**, עם שדה אימייל ושדה
סיסמה, **עבור חשבון שאין לו.**

**מסך ההרשמה כבר כתוב, וכותרתו בדיוק מה שהוא רצה:**

```
src/locales/he.json  login.subtitle.register
"צור חשבון חדש והתחל לארגן"
```

**אבל אי אפשר להגיע אליו מעמוד הנחיתה.** הדרך היחידה היא המתג הקטן בתחתית
הטופס, `login.toggle.toRegister`, "אין לך חשבון? צור אחד".

## איפה זה בקוד

**שני הכפתורים בעמוד הנחיתה מובילים לאותו מקום:**

```
src/pages/LandingPage.tsx:69   ו-:246
to="/login"
```

**ומסך ההתחברות מקבע את התצוגה:**

```
src/pages/LoginPage.tsx:21
const [view, setView] = useState<'login' | 'register' | 'reset'>('login');
```

**שים לב שהמצב השלישי אינו טעות.** ההערה שמעל השורה מסבירה למה יש שלושה מצבים
ולא דגל אחד, וזו הערה טובה. **הבעיה אינה במבנה, אלא בכך שאין דרך להיכנס אליו
במצב שאינו הראשון.**

## ⚠️ ותיקון הניתוב לבדו אינו מספיק

**נמדד באותו סבב:** גם אחרי שהמבקר יגיע למסך ההרשמה, **כפתור השליחה נעול.**

```
src/pages/LoginPage.tsx:246
disabled={isLoading || (isRegisterView && !agreedToTerms)}
```

**כלומר הוא צריך לסמן את תיבת התנאים לפני שהכפתור בכלל נדלק.** זו התנהגות
לגיטימית לחלוטין, **והיא הופכת את הנחיתה מטופס אחד לטופס ועוד צעד.** מי
שיתקן את הניתוב צריך להסתכל גם על זה, אחרת הוא מחליף הפתעה אחת באחרת.

## מה שאינו בעיה, וכדאי לומר את זה

**תווית הכפתור נכונה היום.** בסבב הניסוח היא שונתה מ"פתח אירוע בחינם"
ל"נרשמים ופותחים אירוע, בחינם", **בדיוק כדי שתהיה נכונה בשני המקרים.**

**כלומר הנוסח אינו חסום על הרשומה הזו**, והרשומה אינה חוסמת אותו. **היא רק
הופכת את הכפתור למה שהוא כבר מבטיח.**

## התיקון

**שני קבצים, ואף אחד מהם אינו קובץ יסוד.**

1. `src/pages/LandingPage.tsx:69` ו-`:246`, היעד הופך ל-`/login?mode=register`.
2. `src/pages/LoginPage.tsx:21`, מצב התצוגה ההתחלתי נקרא מהפרמטר במקום להיות
   מקובע. **המצב השלישי נשאר כפי שהוא.**

**בלי מחרוזות חדשות, ובלי נגיעה במסד.**

**ומה שכדאי לבדוק אחרי:** שמבקר שכבר מחובר עדיין מוקפץ ללוח הניהול, ושהמסלול
לאיפוס הסיסמה לא נשבר.

## מה שאינו בהיקף

- **תיבת התנאים עצמה.** היא נדרשת, ואינה באג. **הרשומה רק אומרת שהיא חלק
  מהמסלול ושצריך למדוד אותה יחד איתו.**
- **הניסוח בעמוד הנחיתה.** הוא נעשה בסבב שפתח את הרשומה הזו.
- **שאלת ההרשמה עצמה.** המוצר דורש חשבון מהמארגן במכוון, וזה הבידול שלו:
  **המשתתף הוא זה שאינו נרשם.**
