# 01 — שדרוג Node.js 20 → 22

> 🔴 **חוסם. דדליין קשיח: 30/10/2026.**

## הבעיה

`functions/package.json` מקבע את הריצה ל-Node 20:

```json
"engines": {
  "node": "20"
}
```

Google הודיעה בפריסה האחרונה:

> Runtime Node.js 20 was deprecated on 2026-04-30 and will be decommissioned on **2026-10-30**, after which you will not be able to deploy without upgrading.

## למה זה קריטי

אחרי 30/10/2026 **לא תוכל לפרוס פונקציות בכלל**. לא תיקון באג, לא שינוי מודל AI, לא שום דבר.

זו לא בעיה תיאורטית. ב-23/08 המודל `gemini-2.0-flash` הוצא משימוש על ידי Google בלי התראה, והייבוא החכם קרס. התיקון דרש פריסת פונקציות. אם אותו תרחיש יקרה בנובמבר — תהיה תקוע עם פיצ'ר שבור ובלי יכולת לתקן, ותצטרך לבצע את השדרוג הזה תחת לחץ.

**עדיף לעשות את זה בשקט עכשיו מאשר בחירום אחר כך.**

## מה לעשות

### שלב 1 — לשנות את הגרסה

ב-`functions/package.json`:

```json
"engines": {
  "node": "22"
}
```

### שלב 2 — התקנה מחדש

```bash
cd functions
rm -rf node_modules package-lock.json
npm install
```

### שלב 3 — בדיקה מקומית לפני פריסה

```bash
firebase emulators:start --only functions
```

ודא שהאמולטור עולה בלי שגיאות ושלוש הפונקציות נטענות:
`deleteUserAccount`, `onUserDeleted`, `parseShoppingList`

### שלב 4 — פריסה

```powershell
$env:FUNCTIONS_DISCOVERY_TIMEOUT=60; firebase deploy --only functions
```

## בדיקות אחרי פריסה

- [ ] ייבוא חכם עם טקסט (`2 חלב, פיתות, סלט`) מחזיר פריטים עם קטגוריות
- [ ] ייבוא חכם עם תמונה
- [ ] מחיקת משתמש בדיקה (**לא חשבון אמיתי!**) — ראה אזהרה למטה
- [ ] `firebase functions:log` נקי משגיאות חדשות

## ⚠️ אזהרה על בדיקת מחיקת משתמש

`onUserDeleted` הפכה להרסנית יותר במיזוג של 23/08. היא מוחקת עכשיו גם את **כל הפריטים שהמשתמש יצר** ואת כל השיבוצים עליהם, לא רק את השיבוצים שלו.

הפעולה בלתי הפיכה. לבדוק **רק** עם חשבון בדיקה ייעודי באירוע בדיקה.

## סיכונים

| סיכון | הערכה |
|---|---|
| שינוי התנהגות ב-Node 22 | נמוך — הקוד פשוט, בלי APIs אקזוטיים |
| תלויות לא תואמות | בינוני — `firebase-admin@11` ישן יחסית, ראה [04](04-firebase-sdk.md) |
| זמן השבתה | אפסי — הפריסה מחליפה גרסאות בלי downtime |

## הערה על סדר

לעשות את השדרוג הזה **לפני** שדרוג ה-SDK ([04](04-firebase-sdk.md)), ובנפרד ממנו. שני שדרוגים בו-זמנית = אם משהו נשבר, אין דרך לדעת מה אשם.
