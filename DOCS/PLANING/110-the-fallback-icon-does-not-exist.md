# 110 — האייקון החלופי, זה שאמור לתפוס אייקון חסר, אינו קיים

> 🟠 **בינוני, ונפתחה 05/09/2026** בצ'אט המתאם, אגב ספירת המשקל של
> [108](108-category-icons-are-seven-megabytes-of-gif.md). **נמדד מול האתר החי
> ולא הוערך.**
>
> ⚠️ **לא תוקן אגב.** הוא חוסם את [108](108-category-icons-are-seven-megabytes-of-gif.md)
> ולכן הוא נכנס לפרומפט שלה כתנאי מקדים, ולא כתיקון שנעשה בשקט.

## מה קורה

**בורר הקטגוריות בעמוד האירוע מצייר את האייקון של כל קטגוריה**, ואם הטעינה
נכשלת הוא מחליף אותו באייקון כללי:

```
src/components/Events/CategorySelector.tsx:201
(e.target as HTMLImageElement).src = '/Icons/general.png';
```

**⚠️ והקובץ הזה אינו קיים.** בתיקיית האייקונים יש עשרים ואחד קבצים, שבעה עשר
GIF וארבעה PNG, **ואין ביניהם `general.png`.** **נמדד**, ספירה של התיקייה.

## למה זה לא נראה כשגיאה

**האתר מחזיר 200 לכל כתובת שאינה קיימת.** `public/_redirects` מכיל שורה אחת,
`/* /index.html 200`, **וזו ההגדרה הנכונה לאפליקציית דף יחיד.** התוצאה היא
שבקשה לאייקון חסר אינה מחזירה 404 אלא את עמוד הבית.

**נמדד מול האתר החי, 05/09/2026:**

```
/Icons/general.png    200    text/html    2,627 בתים
/Icons/audience.png   200    image/png   19,245 בתים
```

**כלומר הדפדפן מקבל HTML לתוך תגית תמונה.** הוא אינו יכול לצייר את זה,
**והמשתמש רואה סימן של תמונה שבורה במקום אייקון.**

**⚠️ ורשת הביטחון תופסת את עצמה:** האייקון החלופי נכשל בטעינה בדיוק כמו זה
שהוא בא להחליף.

## מה המשתתף רואה

**קטגוריה שהאייקון שלה חסר מציגה ריבוע שבור בבורר הקטגוריות**, במסך שכל מוזמן
נוחת בו מקישור ההזמנה. **לא אייקון כללי, ולא כלום, אלא סימן שבירה.**

⚠️ **וכמה זה קורה היום: לא נמדד.** צריך אירוע שבו לקטגוריה יש שם קובץ שאינו
בתיקייה, ואת זה אפשר למדוד רק מול המסד החי.

## ⚠️ ולמה זה חוסם את 108

**רשומה 108 תמיר את שבעה עשר קובצי ה-GIF לפורמט אחר, כלומר שמות הקבצים
ישתנו.** ושם הקובץ של הקטגוריה **נשמר במסד**, לא בקוד:

```
src/types (הגדרת הקטגוריה)
icon: string;      // Filename e.g., "meat.png"
```

**כלומר כל אירוע קיים מחזיק במסד מחרוזת כמו `meat.gif`.** אם הקבצים יומרו ושמם
ישתנה בלי מיפוי, **כל אירוע קיים יאבד את כל האייקונים שלו בבת אחת**, ורשת
הביטחון שהייתה אמורה להסתיר את זה שבורה בעצמה.

## מה שכנראה צריך, וזו אינה הכרעה

**אחת משתיים, ושתיהן זולות:**

**להוסיף את הקובץ החסר** לתיקיית האייקונים, בפורמט קל וסטטי.

**או להחליף את החלופה בציור שאינו קובץ**, אות ראשונה של שם הקטגוריה או צורה
מצוירת. **זה לא יכול להיכשל בטעינה.**

## מה שאינו בהיקף

**שורת ההפניה של נטליפיי.** `/* /index.html 200` נכונה לאפליקציית דף יחיד,
**וזו אינה הבעיה כאן.** הבעיה היא קובץ שחסר.
